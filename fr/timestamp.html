Timestamp actuel dans d’autres langages
Langage Secondes Millisecondes
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

En détection automatique, les valeurs à partir de 100 000 000 000 sont lues comme des millisecondes. Choisissez l’unité pour les dates antérieures à 1973 ou postérieures à 5138.

Le temps Unix compte les secondes depuis le 1/1/1970 00:00:00 UTC, sans secondes intercalaires, et il est le même partout dans le monde : le fuseau ne change que la façon d’afficher la date.
