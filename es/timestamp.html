Timestamp actual en otros lenguajes de programación
Lenguaje Segundos Milisegundos
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

En la detección automática, los valores a partir de 100 000 000 000 se leen como milisegundos. Elige la unidad para fechas anteriores a 1973 o posteriores a 5138.

El tiempo Unix cuenta los segundos desde el 1/1/1970 00:00:00 UTC, sin segundos intercalares, y es el mismo en todo el mundo: la zona horaria solo cambia la forma de mostrar la fecha.
