Текущая метка времени в других языках программирования
Язык Секунды Миллисекунды
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

При автоопределении значения от 100 000 000 000 считаются миллисекундами. Для дат до 1973 или после 5138 года выберите единицу вручную.

Время Unix — это число секунд с 1.1.1970 00:00:00 UTC без високосных секунд, и оно одинаково во всём мире: часовой пояс меняет только способ отображения даты.
