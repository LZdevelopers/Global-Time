Aktueller Timestamp in anderen Programmiersprachen
Sprache Sekunden Millisekunden
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

Bei der automatischen Erkennung werden Werte ab 100.000.000.000 als Millisekunden gelesen. Wählen Sie die Einheit für Daten vor 1973 oder nach 5138.

Die Unix-Zeit zählt die Sekunden seit dem 1.1.1970 00:00:00 UTC ohne Schaltsekunden und ist weltweit gleich: Die Zeitzone ändert nur die Darstellung des Datums.
