Timestamp attuale in altri linguaggi
Linguaggio Secondi Millisecondi
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

Nel rilevamento automatico, i valori a partire da 100.000.000.000 vengono letti come millisecondi. Scegli l’unità per date anteriori al 1973 o posteriori al 5138.

Il tempo Unix conta i secondi dal 1/1/1970 00:00:00 UTC, senza secondi intercalari, ed è lo stesso in tutto il mondo: il fuso cambia solo il modo di visualizzare la data.
