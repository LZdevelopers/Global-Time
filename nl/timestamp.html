Huidige timestamp in andere programmeertalen
Taal Seconden Milliseconden
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

Bij automatische detectie worden waarden vanaf 100.000.000.000 als milliseconden gelezen. Kies de eenheid voor data vóór 1973 of na 5138.

Unix-tijd telt de seconden sinds 1-1-1970 00:00:00 UTC, zonder schrikkelseconden, en is overal ter wereld gelijk: de tijdzone verandert alleen hoe de datum wordt weergegeven.
