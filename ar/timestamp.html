الطابع الزمني الحالي بلغات برمجة أخرى
لغة البرمجة ثوانٍ ميلي ثانية
JavaScript Math.floor(Date.now() / 1000) Date.now()
Python int(time.time()) time.time_ns() // 1_000_000
PostgreSQL SELECT extract(epoch FROM now())::bigint; SELECT (extract(epoch FROM now()) * 1000)::bigint;
MySQL SELECT UNIX_TIMESTAMP(); SELECT ROUND(UNIX_TIMESTAMP(NOW(3)) * 1000);
Shell (Linux) date +%s date +%s%3N
PHP time() (int) (microtime(true) * 1000)

في الاكتشاف التلقائي، تُقرأ القيم من 100000000000 فما فوق على أنها ميلي ثانية. اختر الوحدة للتواريخ قبل 1973 أو بعد 5138.

يعدّ وقت Unix الثواني منذ 1/1/1970 00:00:00 UTC، دون الثواني الكبيسة، وهو نفسه في العالم كله: المنطقة الزمنية تغيّر طريقة عرض التاريخ فقط.
